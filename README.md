# 🧠 Rock vs Mine Detection System

This project uses a Logistic Regression Machine Learning model to predict whether a sonar signal is a **rock** or a **mine**, based on 10 sonar features.

## 🎯 Features
- Logistic Regression model
- Flask web interface
- Ocean-themed animated frontend
- Prediction history tracking
